#  SEO Intelligence SaaS 🚀

A high-performance, AI-driven SEO automation platform built with FastAPI and MongoDB.

## 🌟 Features
- **Neural Strategic Profiling**: AI-driven niche and location extraction.
- **Elite Competitor Intelligence**: Robust market analysis using Multi-Model AI.
- **High-Fidelity Scraping**: Powered by Crawl4AI and high-performance proxies.
- **Dynamic SEO Roadmap**: Automated keyword engineering and on-page optimization.
- **Serverless SaaS**: Ready for Vercel with persistent MongoDB authentication.

## 🏗️ Project Structure
```text
.
├── agents/             # Modular SEO Agents (Expert, OnPage, etc.)
├── core/               # Core logic (DB Manager, Model Router)
├── api/                # Vercel Serverless Entry Points
├── public/             # Static Dashboard Assets
├── reports/            # Generated Intelligence Reports
└── requirements.txt    # Production Dependencies
```

## 🛠️ Environment Setup
Add the following to your environment variables:
- `MONGODB_URI`: Your MongoDB Atlas connection string.
- `GROQ_API_KEY`: For fast reasoning.
- `SAMBANOVA_API_KEY`: For high-throughput AI tasks.
- `SECRET_KEY`: For JWT session signing.

## 🚀 Deployment
1. Push to GitHub.
2. Link to Vercel.
3. Configure Environment Variables.
4. Profit!
